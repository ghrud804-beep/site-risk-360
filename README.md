# 하폐수처리장 360° 위험성평가

사진에서 위험 위치에 핀을 표시하고 위험요인·점수·대책을 정리하는 정적 웹 앱입니다.

## 사용

- 웹 주소를 열면 실습용 예시 사진을 사용합니다.
- 사진 바꾸기, 핀 추가·편집, AI 결과 JSON 붙여넣기를 사용할 수 있습니다.
- 작업은 각 사용자 브라우저에 저장됩니다. 사용자 간 자동 동기화·공동 편집은 제공하지 않습니다.
- 다른 사용자와 작업 내용을 전달하려면 작업 저장으로 JSON을 내려받아 전달하고 작업 불러오기를 사용합니다.
- CSV 내보내기와 인쇄 기능을 사용할 수 있습니다.

## GitHub Pages 배포

1. 저장소 루트에 index.html, site.jpg, .nojekyll을 둡니다.
2. Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
3. main 브랜치와 /(root)를 선택하고 저장합니다.
4. 배포 완료 뒤 Pages에 표시된 웹 주소를 공유합니다.

## 범위

실습용 도식 이미지와 앱 코드만 포함합니다. 개인 작업 JSON·평가서·실제 현장 사진을 이 저장소에 추가하지 마세요. 라이선스 부여는 소유자가 별도로 결정합니다.
